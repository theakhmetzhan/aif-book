# Ushqyn · The Spark That Learned to Think

A pop-up book of AI fundamentals: an interactive 3D paper book you can turn page by page and walk around. Look straight down (Read) and every pop-up folds back into the flat diagram it explains.

Endterm project for AI Fundamentals (AIF1303), QAIRU, Fall 2026, by Akhmetzhan Turlybek. This edition contains Chapters I–III.

**Read it:** https://theakhmetzhan.github.io/aif-ushqyn/

Controls: scroll or ← → to turn pages · drag to walk around · R or the Read button to look straight down (click a page to zoom). On phones: swipe up to turn, drag sideways to walk around.

Develop: `npm i && npm run dev`. Figure data in `src/data/` is generated and checked in Python.
