# PROTOTYPE: what should the Ushqyn book look like?

Throwaway. Four structurally different reading experiences, same sample content (Preface, Chapter II "The Paths" with a live BFS/A* toy, opening of Chapter III).

Run: `npm i && npm run prototype` → http://localhost:5173/prototype/?variant=A

- **A · Fly-through**: one continuous scroll-driven camera journey; captions fade over the world (closest to the reference video).
- **B · Living book**: a literal open book; prose on the left page, a living 3D plate on the right; page turns.
- **C · Scrollytelling**: text column scrolls, sticky 3D stage reacts per paragraph; chapter rail.
- **D · Constellation map**: non-linear; ten chapter-stars in the sky, click to dive in, chapter opens in a drawer.

Switch with the pink bar or ← →. Variant B turns pages with PageDown/PageUp/space/scroll.
